# アート基準（1995年スクウェア風 16bit ドット絵）

本書は本作の全アート（キャラ・オブジェクト・タイル・背景・UI）が満たすべき**客観基準**である。
「いい感じ」のような主観語で品質を語らず、下記の数値基準と参照画像との並置比較で判定する。

## 1. 参照（著作物のため同梱しない。リンク参照のみ）

| 参照 | 用途 | 出典 |
|------|------|------|
| ファン作 FF 風キャラドット絵一覧 | キャラの**寸法・頭身・陰影段階・輪郭**の基準 | https://jp.pinterest.com/pin/456059899758535814/ |
| クロノ・トリガー スプライト実寸表 | 実機の**キャラ/敵/ボスの寸法レンジ** | https://www.snesmaps.com/maps/ChronoTrigger/sprites/ChronoTriggerSprites.html |
| SNES ハード制約 | **1 スプライト 15 色 + 透明**、画面 256×224 | https://forums.nesdev.org/viewtopic.php?t=15953 |

### 1.1 参照から計測した数値（2026-09-08 計測）

- ファン作ドット絵（Pinterest）: 1 キャラの論理寸法 約 **38〜44 × 54〜64 px**、頭身 **2.5〜3**、目は 2×3px 前後で白目＋虹彩＋ハイライトの 3 色、髪は 3〜4 段階の明暗、輪郭は黒ではなく**各素材の最暗色**、服の皺・袖口・ベルト等の小物が 1px 単位で描かれている。
- クロノ・トリガー実機: パーティ 13×33〜24×32（クロノ 16×35）、敵 16×15〜176×123、ボス最大 256×144。
- 聖剣伝説2 実機: 主人公 約 24×32（画面高の約 1/7）。超魔界村: アーサー 約 28×32。

### 1.2 本作の位置づけ

参照ドット絵はキャラ単体で約 40×60 セル（FF6 バトルスプライト級より一段細かい）。生成モデル（Gemini 2.5 Flash Image）の自然なドット密度もキャラ約 40×60 セル・ボス約 100 セルで、これに一致する。
実測（エッジ投影によるセル抽出）ではキャンバス一杯のキャラが **約 48×100 セル**、雑魚 約 50×100、ボス 約 120×150 セル。
そこで本作は **内部解像度 768×672（SNES の 3 倍密度、整数倍表示）**、タイル 48×48、**主人公 約 48×100 セル**（画面高の 15%、超魔界村のアーサー 14% と同等）を採用する（2026-09-08 決定、512×448 案は誤計測につき撤回）。
画面内タイル数は 16×14 で SNES と同じ。物理は世界座標（1 世界単位 = 3 画面画素）で従来どおり。
初版の 16×24 は根拠なし、改訂の 24×32・32×48 は手描き前提の値で、いずれも生成モデルの密度と合わず廃止。

### 1.3 社内の尊重物（挿絵級の画風。2026-09-10 ユーザー指定）

`assets/sprites/ending/scene1.png`（キャラあり）と `scene6.png`（静物）を**画風の尊重物**とする。挿絵級（カットイン・エンディング・タイトル等の一枚絵）はこの 2 枚と同じ物差しで比べ、外れていれば修正対象（IMP-022）。
計測は `tools/style_check.py`（同じ関数で尊重物と対象を測る）。2026-09-10 の実測:

|------|------|----------------|--------------------|------------------|-------------|------------------|
| scene1（尊重物） | 32 | #220d30（hue 276, val 0.19） | **0.16** | 0.09 | 0.39 / 0.44 | **4.3**（帽子込み 156 セル、頭 32、髪上端〜靴底 138） |
| scene6（尊重物） | 32 | #1e0a24（hue 286, val 0.14） | **0.20** | 0.10 | 0.48 / 0.39 | — |
| cutin 4 枚（v1、台帳 225。不採用） | 24 | #392b4d〜#452b46（val 0.24〜0.30） | 0.35〜0.40 | 0.11〜0.15 | 0.25〜0.43 / 0.48〜0.71 | **2.5**（帽子込み 76、頭 26） |
| cutin 4 枚（**v2**、台帳 226。尊重物＋立ち絵ベース添付） | 32 | #291430〜#3b142c（hue 285〜328, val 0.19〜0.23） | **0.17〜0.23** | 0.10〜0.12 | 0.34〜0.43 / 0.41〜0.58 | 腰上の構図。頭 ≈ パネル高の 1/4（実測 stardust: 頭 29 セル / 高 112） |

flat が尊重物の 2 倍あるものは「平坦に塗った絵」で、ユーザーが「絵柄が別物」と見た 4 枚のカットイン v1 と scene3〜5 がそれに当たる（scene2 は輪郭の明度だけ外れる）。同じ物差しで、尊重物と立ち絵ベースを添付して描いた v2 は flat 0.17〜0.23 に入った（`test-results/shots/cutin_v2_vs_v1.png`）。頭身は色では測れないので `style_check.py --grid` の 4 倍格子画像で読む。

## 2. 数値基準

### 2.1 解像度・寸法

| 項目 | 基準 |
|------|------|
| 内部解像度 | **768×672**。整数倍で拡大表示、非整数スケール禁止 |
| タイル | 48×48 |
| 主人公 | 本体 **幅 40〜56 / 高 90〜110 セル**。当たり判定は世界単位 12×28（しゃがみ 12×18）。走り撃ちコマ（run1s/run3s）は前に突き出した杖と火花を含むため幅 110 セルまで（本体は同じ）。詠唱コマ（cast1/cast2、強化魔法）は杖を頭上に掲げる／前に突き出すため **高 140・幅 110 セルまで**（2026-09-10 実測: cast1 70×131・髪幅 34、cast2 97×99・髪幅 36。idle_nohat 44×103・髪幅 33 に対し頭部の寸法は ±3 セル以内で、伸びているのは掲げた杖と伸ばした腕だけ） |
| 強化魔法のエフェクト（`magicfx/`） | 単体の演出物は **高 30〜150 セル**、色数 10〜15。心臓の花（flower1/2 82×146・82×133）は 3 タイル級を意図した特大（2026-09-10 決定。「おおげさなくらい豪華に」ユーザー指示）。カットイン（`cutin/`）は 24 色までの不透明パネル |
| 雑魚敵 | 本体高 **80〜120 セル**（主人公の 0.8〜1.2 倍）。例外: 人魚 1 コマ目は水面上の半身のみ（下限 40）、綿あめの繭は天井からの吊り糸を含むため 145 まで（2026-09-10 実測 49×137・58×137。繭の本体は 60 セル前後で、残りは糸） |
| ボス | 本体高 **140〜200 セル**（画面高の 20% 以上） |
| 弾・アイテム | 24〜48 セル |
| アニメ | 歩行 4 フレーム以上、攻撃 2、ジャンプ 2（上昇/下降）、被弾 1、死亡 2 以上。敵は 2 フレーム以上、ボスは状態ごとに 2 以上 |

### 2.2 色・陰影

| 項目 | 基準 |
|------|------|
| 1 スプライトの色数 | **10〜15 色**（透明除く）。後処理で 15 色に量子化。10 色未満は情報不足で不合格 |
| 明暗ランプ | 主要素材（髪・肌・服・金属）ごとに **最低 3 段階**（影・基本・光）。主人公の髪と服は 4 段階 |
| ハイライト | 髪・金属・目に 1px のスペキュラを必ず置く |
| 輪郭 | 1px。**純黒（#000000）禁止**。隣接素材の最暗色、または暗紫〜暗茶の統一色。内側の分割線は輪郭より 1 段明るい色 |
| ディザ | 背景の空・水面・遠景グラデーションに市松ディザを用いる。キャラには原則使わない |
| 生成方法 | Gemini 2.5 Flash Image にドット絵として直接描かせ、セル中心サンプリングで論理画像化する（縮小フィルタ禁止、docs/gen-pipeline.md） |

### 2.3 造形

| 項目 | 基準 |
|------|------|
| 頭身 | 主人公・人型敵 **2.5〜3 頭身**。頭幅は本体幅の 60〜70% |
| 顔 | 目 2×3px 以上（白目＋虹彩＋ハイライト）、眉/まつ毛 1px、口 1〜2px、頬に 1 色 |
| シルエット | 帽子・ほうき・ドレス裾など**キャラ固有の輪郭要素**を 3 つ以上。塗りつぶし 1 色で判別できること |
| 敵の「えげつなさ」 | 各敵に傷口・血・綿・骨のいずれかを **本体面積の 5% 以上** |

### 2.4 背景・タイル

| 項目 | 基準 |
|------|------|
| パララックス | 空（固定）＋ **遠・中の 2 層**＋地形手前の装飾。各層で速度差。中景は **1 画面 px/セル**（スプライトと同密度）で、両端に余白を持つ層を 2〜3 種生成して連結し繰り返し感を消す。遠景 2、空 3 画面 px/セル（1 リクエストの横幅制約による妥協） |
| 空 | 12 帯以上のディザ付きグラデーション、月/雲/星のいずれかを含む |
| 各層の色数 | 8 色以上。シルエット 1 色塗りは禁止（最低 3 段階の明暗で奥行きを出す） |
| 地形タイル | 上面（草/砂糖/石床）に 3 段階以上の明暗＋草の葉・ひび・石目などの 1px 詳細。土中に石・根・骨などのアクセント。**同一タイルの連続は 3 バリエーション以上で崩す** |
| 装飾 | 墓石・花・ろうそく等の装飾は本体に 3 段階以上の明暗と落ち影 |

### 2.5 UI・テキスト

| 項目 | 基準 |
|------|------|
| フォント | UI はスクリーン解像度で描く。本文は DotGothic16 の **2 倍（32px）**、枠線 2px＋ベベル 1px、ミニフォントは 1 ドット 2px。配置は 256×224 の論理座標で行い **実測幅で折り返し**、1 行 240 論理 px 以内 |
| 窓 | 内容に合わせて自動サイズ。画面外周 8px のセーフマージンを侵さない |
| HUD | 上 26px 帯。数値はミニフォント（3×5） |

### 2.6 挿絵級（カットイン・エンディング・タイトル）

| 項目 | 基準（尊重物 scene1 / scene6 の実測から。§1.3） |
|------|------|
| 色数 | **28〜32**（スプライト級の 15 とは別枠） |
| 粒子 | flat（横に隣り合う画素が同色の率）**≤ 0.28**、dither（市松率）**≥ 0.07**。全面に 1 セルの粒子・市松があること。平坦塗りの面は例外的 |
| 輪郭 | 最暗色が暗紫〜暗い葡萄色（hue 255〜335、HSV 明度 ≤ 0.23）。#220d30 / #1e0a24 が基準色。上限は、同じ手順で描いた cutin v2 の暖色パネル（薔薇の空・蝋燭の光）の最暗色が hue 315〜328・val 0.23 に出たことから置いた |
| 頭身 | 主人公は **帽子なし 4.3 頭身**（scene1 実測）。目は 4 セル前後の細い形。チビ（2.5 頭身・大きな目）はスプライト級専用で、挿絵級では不合格 |
| 生成手順 | 毎回 **画風の尊重物 1 枚＋キャラ立ち絵ベース 1 枚**を添付する（specs の `style_refs`、契約は `assets/gen/prompts/_illust_style.txt`）。立ち絵ベースは scene1 から切り出した `assets/gen/ref/lyrica-illust.png`（桃）／`lyrica-illust-gold.png`（衣装帯だけ金へ回した派生。リクエスト不要）。同じ組の複数枚は 1 リクエストのシートで描く |
| 検査 | `tools/style_check.py` が manifest に flat / dither / outline を書き足し、`test/art-standard.test.js` §2.6 が帯を検査する。帯の外の既存絵は PENDING（IMP-022）として列挙し、直したら外す |

## 3. 判定手順

1. **自動テスト**（`npm test`）: 寸法、色数（10〜15）、純黒輪郭なし、明暗ランプ 3 段階以上、背景層数、テキスト折り返しを検査する。
2. **カタログ並置**（`catalog.html`）: 各スプライトを 3〜4 倍で表示し、参照画像（外部 URL、同梱しない）と同倍率で並置して目視確認する。
3. **シーン合成**: 背景＋タイル＋キャラを 1 画面に合成し、ゲーム画面としての密度を確認する。
4. 合否は上記 1〜3 の**証跡（スクリーンショットとテスト結果）**を添えて報告する。「いい感じ」等の主観表現のみでの合格報告は禁止。
