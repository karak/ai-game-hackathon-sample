# テスター向け手引き（M5 出口条件: 5 人・完走率 60% 以上・平均 3 時間以内）

対象 URL: https://magical-lyrica.karak97.workers.dev （PC ブラウザ推奨。スマホは縦持ちでタッチ操作）

## お願いすること

1. **はじめから**で第一章から遊び、エンディング（8 章）まで目指す。コンティニューは何度でも可（面の先頭・スコア 0）。
2. 途中でやめるときはポーズ（Esc / P / パッド START）→「タイトルへ」で戻る。次回は「つづきから」で到達した章から再開できる。
3. 終わったら（完走でも途中でも）**オプション → テスター報告を コピー** を押し、クリップボードの JSON を送る（Issue の「テスター報告」欄、または連絡手段に貼る）。
   - JSON に入るもの: ビルド ID、ブラウザの UA・言語・画面サイズ、パッド名、各プレイ（開始章・到達章・クリア・死亡数・コンティニュー数・プレイ秒）、死亡地点の集計。**氏名やアカウントは入らない**。
4. ゲームパッドで遊ぶ人は、最初に **オプション → ゲームパッド** の行を見て、パッド名が出ること・ボタンを押すと `[A]` `[B]` のように名前が出ることを確認する。出ない／違うボタンになる場合はその行の表示と機種名を報告に添える。動かないボタンは「ジャンプ」「まほう」などの行で決定 → 使いたいボタンを押すと割り当て直せる。
5. 詰まった場所・理不尽に感じた場所・表示の崩れは、スクリーンショットと一緒に不具合報告（GitHub Issues の「不具合報告」テンプレート）へ。

## 計測の集め方（開発側）

- 受け取った JSON を `docs/plan/logs/testers/<名前や番号>.json` に保存し、`node tools/tester_stats.mjs` で集計する（完走率・完走者の平均時間・章ごとの到達数・死亡の多い章）。
- 完走率 60% 未満、または平均 3 時間超のときは、死亡の多い章から難易度を調整する（`docs/plan/08-backlog.md` IMP-017 の多発地点と照合）。
- 実機ゲームパッドの結果は「ゲームパッド」行の表示（パッド名・ボタン名）と機種名を `docs/release/known-issues.md` の該当行に記録する。
