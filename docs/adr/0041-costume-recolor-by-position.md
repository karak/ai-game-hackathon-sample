# ADR-0041: 私服・金衣装の派生は画素の位置分類で行い、私服は白・紺・赤の 3 色を足して 15 色に収める

- 状態: 採用
- 決定日: 2026-09-13
- 記録日: 2026-09-13
- 関連: BUG-006、`tools/derive_variants.py`（`color_roles` / `classify_costume` / `trim_mask` / `apply_costume`）、`test/art-standard.test.js`（色数 10〜15）、catalog キャラクターシート「私服」「フルブルーム」、commit db580a6

## 背景

私服・金衣装は帽子なし idle から色 → 色の写像（`rule_map` / `costume_map`）で派生していた。2026-09-13 に idle_nohat 44×103 を画素単位で読んで計測した限界:

1. 髪の陰影 (209,89,134) がスカートの襞にも使われ、髪ガードで置換されず白いスカートに桃色の斑が残る（idle で 252 画素中 79 が襞）
2. 前髪のハイライトに衣装の桃 (230,122,156) が 48 画素使われ、白（私服）／金に化ける
3. 襟・袖口・裾フリルのクリーム (251,237,232 / 236,227,216) は目の白・靴下・頬と同色で、色だけでは区別できない → 白いブラウスに溶けて見えない（BUG-006 の本体）
4. 肌影 (204,122,141) も桃系の判定に入って白になり、腕に白い斑が出ていた

## 決定

1. 各コマの画素を **髪確定色**（帽子なし idle で平均 y が高さの 30% より上・20 画素以上: (229,151,163) (234,133,163)）と **衣装確定色**（平均 y が 45% より下で彩度 0.7 超か明度 0.3 未満: (180,17,88) (85,31,80)）を種に分類する。確定色の集合は基準コマ（idle_nohat）のものを全コマで使う（コマ単独だと髪が大きいコマで襞の色が髪確定色に入る）
2. 明るい桃（明度 0.6・彩度 0.6 以上）は 5×5 近傍に髪確定色が 2 個以上なら髪、それ以外は衣装の種。衣装と判定された 3 画素以下の孤立成分は髪へ戻す
3. 陰影・輪郭の候補色は両方の種からの多ソース BFS（4 近傍、候補画素の上だけ）で近い側へ。届かないものは変えない。肌影（明度 0.6 以上・彩度 0.5 未満）は候補にしない
4. 縫い取り（私服のみ）: クリームの連結成分のうち、衣装画素との隣接が 3 画素以上・瞳の色 (71,58,107) に隣接しない・120 画素以下のもの（実測: 襟・袖口・裾は隣接 4〜43、目の白は 0〜1 で瞳隣接 11〜28、杖の星は 2、詠唱の光は 361 画素）
5. 私服のパレット: 白 (232,232,240)・紺 (38,57,122)・赤 (217,38,43) の 3 色だけを足し、襞は肌影 (204,122,141)、輪郭・濃影は靴の暗紫 (48,35,69) を共有する。金は 3 色の固定ランプ (247,205,120) (222,160,60) (197,133,9)＋暗紫。帽子つきコマ（金）の上 30% は髪・帽子扱いで、飾りリボンは全コマ桃のまま（紅・濃紫は近い髪系色へ寄せる）

## 結果

- 全 15 コマ × 私服・金が **15 色**（hurt2 は白寄せ派生で 17 色、テストは従来どおり除外）。桃 (230,122,156) の残存は 15 コマとも 0 画素、帽子領域の金は 0 画素
- 残る妥協: 襞が多いコマ（run3s・jump）はスカートの半分近くが肌影色の薄桃になる（15 色に収めるため白の陰影色を持てない）。run3s の靴下の一部（裾に接する）が赤。ほうきと同じくユーザーの目で見た評価を待つ
- golden は涙の川・工房の 600 フレーム目（衣装が plain）と画廊（金）だけ変わり、軌跡・メニュー・他の面は不変
- 試行は 6 回（多数決 → 確定色だけの BFS → 明るい桃を種に → 基準コマの確定色 → 縫い取りの閾値 → 帽子領域）。各回とも画素数で計測して次を決めた
