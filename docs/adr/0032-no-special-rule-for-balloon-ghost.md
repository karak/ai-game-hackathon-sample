# ADR-0032: 風船の亡霊に専用規則は置かない

- 状態: 採用
- 決定日: 2026-09-12
- 記録日: 2026-09-13
- 関連: IMP-015、`tools/record_demos.mjs`（コメントに記録）

## 背景

穴の上を漂う亡霊の下で「跳ばない／止まって撃つ／下がる」を試したが、雨と接触の死亡が 1 → 3 に増えた。

## 決定

亡霊専用の規則は置かず、一般規則（敵待ち・回避候補・跳び越え）のままにする。

## 結果

遊園地は 3780・0 死で最も遠くまで進む。
