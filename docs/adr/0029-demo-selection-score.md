# ADR-0029: デモの採用基準は 進み − 400×死亡 − 400×ゲームオーバー

- 状態: 採用
- 決定日: 2026-09-12
- 記録日: 2026-09-13
- 関連: IMP-015、`tools/record_demos.mjs score`

## 背景

死亡の重みが 250 だと、塔で「1 死 1800」の素朴なボットが「0 死 1445」の賢いボットに勝った。放置デモで死ぬ方が進みの短さより目立つ。

## 決定

`score = progress − 400 × deaths − 400 × (gameover ? 1 : 0)`。死なずに止まっているだけの変種は進みが短いので採られない。

## 結果

塔で 0 死のボットが採用された。
