# ADR-0028: デモボットはドレスを優先して取る

- 状態: 採用
- 決定日: 2026-09-13
- 記録日: 2026-09-13
- 関連: IMP-015、`tools/record_demos.mjs`

## 背景

ユーザー指示「ドレスのアイテムは単位時間あたりの x が多少下がっても優先して取得する」。ドレスは宝箱からしか出ず、箱は足場の上に置かれている（第二章の 2 個目は地面より 48 px 上）。

## 決定

落ちている dress / golddress（220 px 以内・同じ高さ帯）へは後ろでも向かう。開ける価値のある箱（私服なら dress、ドレスで 3 個目なら golddress）が 140 px 以内・90 px 以内の高さなら、着地 y を返すシミュレーションで足場に乗る跳び方を選んで登り、同じ高さで止まって撃つ。真下で 90 フレーム乗れなければ諦める。価値の無い箱は開けない（武器が変わり狙いが狂う、乱数の消費で後の展開が変わる: 全箱を開ける版では第二章が 0 死 3040 → 1 死 1597 に崩れた）。

## 結果

第一章・第二章で各 1 着取得、進み 3683 → 3613 / 3040 → 3034、全 8 面 0 死のまま。

## 証跡

`assets/demo/stage1.json`、`stage2.json`（`dresses=1`）
