# ADR-0002: 帽子は原画のものを使い、実行時に重ね描きしない

- 状態: 採用
- 決定日: 2026-09-09
- 記録日: 2026-09-13
- 関連: BUG-009、`tools/derive_variants.py ensure_hat`

## 背景

帽子付きで生成したコマの上に別パーツの帽子を重ねていたため二重になり、上側が 7 世界単位浮いて見えた（ユーザー指摘）。

## 決定

原画に描き込まれた帽子をそのまま使う。モデルが帽子を落としたコマだけ `derive_variants.py ensure_hat` で合成する。合成位置は帽子込み原画の計測から（帽子上端 = 髪上端 − 8 セル、中心 x = 髪中心 − 6.4 セル）。私服セットは v2 固定。

## 結果

帽子の二重描画が消える。合成の当て推量（「つばを 6 セルかぶせる」）は 20 セル以上ずれたので使わない。
