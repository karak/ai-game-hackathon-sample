# ADR-0011: 英語 UI は日本語文字列をキーにした辞書と t()

- 状態: 採用
- 決定日: 2026-09-10
- 記録日: 2026-09-13
- 関連: IMP-008、`src/shared/i18n.js`、`src/content/story.js`、`test/i18n.test.js`

## 背景

英語表示を追加するが、ソースの日本語文字列をキーのままにして差分を小さくしたい。

## 決定

`EN` 辞書と `t()`。物語本文は `story.js` に両言語（場面数・行数を揃える）。初回はブラウザ言語、以後は保存 `lang`。辞書漏れは `test/i18n.test.js` が `t()` の呼び出しを走査して検出。

## 結果

文言を足したらフォントのサブセットも作り直す（ADR-0036）。

## 証跡

`test/i18n.test.js`、`e2e/boot.spec.js`「English UI」
