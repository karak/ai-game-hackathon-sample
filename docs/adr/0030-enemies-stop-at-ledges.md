# ADR-0030: 主人公へ寄る敵は足場の縁で止まる（腐ったケーキ）

- 状態: 採用
- 決定日: 2026-09-12
- 記録日: 2026-09-13
- 関連: BUG-021、`src/stage/entities/enemies.js RottenCake`

## 背景

鏡の塔で上の足場のケーキが主人公の x へ寄って崖から落ち、落下しながら蛆を吐き続けて下の主人公に降り注いだ（落下中のケーキ 3 体が同じ列に居た）。

## 決定

進む先の足元が床（solid / 片道床）でなければ歩かない。

## 結果

golden は塔の軌跡・ハッシュだけ更新（他 7 面・画面・画廊は不変）。他の歩く敵に同じ症状が出たら同じ縁チェックを入れる。
