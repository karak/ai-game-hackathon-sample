# ADR-0031: デモボットは止まって撃つ前に敵の方を向き、敵弾は実物の物理で先読みする

- 状態: 採用
- 決定日: 2026-09-12
- 記録日: 2026-09-13
- 関連: IMP-015、`tools/record_demos.mjs turning / shotPath`

## 背景

向きは動いた瞬間にしか変わらないので、下がった直後は後ろ向きに撃ち続けて「撃っても減らない」になっていた（第二章の這う繭 x=726、塔のはしご上のケーキ）。跳ねる弾を「床の上の箱」で近似すると高く跳ねる蛆や空中からの見え方が合わなかった。

## 決定

止まって撃つのに敵と反対を向いていたら 1 フレームだけ進行方向へ寄る（`turning`）。敵弾は `EnemyShot.update` と同じ物理（重力・床で消える・跳ねる弾の 0.5 倍反発と横 0.7 倍）で 60 フレームぶん軌道を先読みし（`shotPath`）、全候補で使い回す。

## 結果

8 面の総死亡 6 → 3 → 0 に至る修正群の中核。
