# ADR-0003: 走り撃ちは 2 コマ（run1s / run3s）で表す

- 状態: 採用
- 決定日: 2026-09-09
- 記録日: 2026-09-13
- 関連: IMP-016、`src/stage/entities/player.js frame()`

## 背景

走りながら撃つコマを 4 枚描かせると、通過コマでは 2 回とも杖が描かれなかった。

## 決定

`run1s` / `run3s` の 2 コマ（帽子なしで生成し帽子を合成、杖込み幅 103）。射撃中は 12 tick ずつ交互に出す。通過コマは不採用。

## 結果

生成リクエストを節約しつつ杖の有無が揺れない。
