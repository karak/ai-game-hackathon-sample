# ADR-0004: コマの分割は連結成分で切る

- 状態: 採用
- 決定日: 2026-09-09
- 記録日: 2026-09-13
- 関連: BUG-013、`tools/postprocess.py split_frames_masked`

## 背景

2 コマ横並びの原画を列の占有で割ると、隣のコマの部品（腕・杖）が混入した。

## 決定

連結成分でコマを切り、欠片は最寄りのコマへ寄せる。期待数に足りなければ占有最小の列で割る。

## 結果

隣コマの混入が無くなる。付属物（飛沫・ハート）が別成分になることがあるので、単体は「不透明画素が最多の成分」を採る。
