# 00. ビジョンとスコープ

## 一言で

**「1995 年のスクウェアの絵で動く、超魔界村の手触りのアクション。主人公はかわいい魔法少女、敵はかわいい見た目で中身がえげつない。」**

## 対象プレイヤー

- SNES 世代のアクション／RPG 好き。難しいアクションを「覚えて攻略する」ことを楽しめる人
- ドット絵・レトロ表現に価値を感じる人。ジャンル反転（魔法少女 × ゴア）の悪趣味さを笑える人
- プレイ時間: 1 周 45〜60 分（8 ステージ × 5〜7 分）、慣れれば 30 分。周回・スコアアタック要素で 5〜10 時間

## プラットフォーム

- ブラウザ（デスクトップ Chrome / Firefox / Safari、キーボード＋ゲームパッド）。将来的に Electron/Tauri パッケージ化と itch.io 配信を想定
- 内部解像度 768×672（SNES の 3 倍密度）、整数倍拡大。60fps 固定ステップ

## 設計の柱（変えない）

1. **超魔界村の身体性**: 空中制御なしの固定ジャンプ、二段ジャンプで軌道修正、被弾で装備喪失、武器切替、制限時間。1 ステージは「覚えれば通せる」密度で作る
2. **1995 年スクウェア風の絵**: 主人公約 100 セル、雑魚 60〜130、ボス 140〜200。1 スプライト 15 色、暗紫の輪郭。中景以上はスプライトと同密度（`docs/art-standard.md`）
3. **ジャンル反転**: 敵は必ず「かわいい造形 ＋ 傷・血・綿・毒のいずれか」。主人公は淡々と処理する。被弾は「変身解除→私服」で下着表現はしない
4. **客観的な品質判定**: 数値基準・参照画像との並置・テスト・スクリーンショットで判定する

## スコープ（完成版 v1.0）

| 含む | 含まない（v1.0 では） |
|------|------------------|
| 8 ステージ＋ボス 8 体（うち最終は 2 段階） | オンライン要素、ランキングサーバー |
| ギミック 8 種（04-stages 参照） | レベルエディタの公開 |
| 武器 4 種 × 溜め魔法 4 種、ドレス 3 段階 | 多言語対応（日本語＋英語 UI のみ） |
| タイトル／デモ／エンディング／クレジット／オプション／セーブ（進行・ハイスコア） | ボイス |
| ゲームパッド対応、キーコンフィグ | モバイル最適化（動作はする） |
| BGM 8 曲＋ジングル、SFX 60 種 | |

## 成功の定義

- 初見プレイヤーが 1 ステージを 10 分以内にクリアでき、8 ステージを 3 時間以内に完走できる（テストプレイ 5 人）
- 全素材が `docs/art-standard.md` の数値基準を満たし、カタログで検査できる
- 60fps を維持（Chrome、M1 相当で CPU 30% 以下）
