# 06. 素材制作計画

生成手順の正典は [../gen-pipeline.md](../gen-pipeline.md)、品質基準は [../art-standard.md](../art-standard.md)。本書は**何をどの順で、何リクエストで作るか**。

## 6.1 1 面あたりの素材セット（標準）

| 種別 | 数 | リクエスト | 備考 |
|------|----|-----------|------|
| 空 | 1 | 1 | 3 px/セル。ディザ帯を粗く描くプロンプト |
| 遠景 | 2 分割 | 2 | 1 倍密度化のため左右 2 枚（両端余白あり、連結） |
| 中景 A/B/C | 3 | 3 | 両端余白、同じ地平線 |
| 地形帯 | 1 | 1 | 地表／足場／地中の 3 帯 |
| 装飾 | 4〜8 | 1〜2 | 4 体 1 行 |
| 雑魚 | 2 種 × 2 コマ | 2 | 2 フレーム横並び |
| ボス | 1 体 × 2〜3 コマ | 2〜3 | 待機／攻撃／被弾 |
| 敵弾・ギミック小物 | 4〜8 | 1〜2 | |
| 予備（再生成） | — | 3 | 失敗率 15〜20% の実測に基づく |
| **合計** | | **≈ 17〜20** | |

8 面版の新規 5 面（第 3 章のボス差替え含む）で ≈ 100、共通素材（魔法 4 種の演出、エンディング 6 場面、UI フォント、タイトルロゴ）で ≈ 25、合計 ≈ 125。現セッション残 131 でぎりぎり収まる見込みだが、再生成率が上がれば追加予算が必要。

## 6.2 制作順序（1 面）

1. **コンセプト行**を書く（04-stages のテーブル 1 行 ＋ かわいい要素 1・えげつない要素 2）
2. `specs.json` にエントリ追加（箱・フレーム数・出力名・パレット共有）
3. 背景（空→遠→中）→ 地形帯 → 装飾 → 雑魚 → ボス の順に生成。**各段階でカタログを見て合否**（背景の色域と敵の色が喧嘩しないか）
4. `build_sprites.py` → `derive_variants.py`（必要なら）→ `npm test`
5. レベルデータを書き、`test/level.test.js` の到達性テストを通す
6. ボット自走 → カタログ「ステージ構成」→ スクリーンショットを `docs/plan/logs/<stage>/` に保存

## 6.3 命名・配置

- raw: `assets/gen/raw/<spec>-vN.png`、プロンプト: `assets/gen/prompts/<spec>.txt`
- 出力: `assets/sprites/<group>/<name>.png` ＋ 同名 `.json`（`group` = player / enemies / bosses / shots / items / deco / bg / tiles / fx / ending）
- `src/gfx/manifest.json` は生成物。手で編集しない
- 版固定は `specs.json` の `use: "vN"`

## 6.4 生成の禁止事項・注意（実測）

- 「1 セル = N px」「テンプレートに沿って」は守られない。**2 フレーム横並び**でサイズを安定させる
- 欠損表現（首なし等）は頭を描き足される。別表現に変える
- 衣装変更・装飾の脱落は起きる。**後処理（色置換・合成）で吸収**する前提で設計する
- 背景に「月・空」を描かせない指示は必須。中景は両端余白を必ず要求

## 6.5 QA チェックリスト（素材 1 点ごと）

- [ ] `fits: true`、色数がカテゴリ範囲内（`npm test`）
- [ ] カタログ 1:1 表示で、輪郭が暗紫系・1 セル幅、面の 3 段階以上の明暗がある
- [ ] 主人公との高さ比が 04-stages の範囲（雑魚 0.6〜1.3、ボス 1.4〜2.0）
- [ ] 足元基準線に接地している（浮遊敵は除く）
- [ ] ゴア要素が面積 5% 以上（雑魚）
- [ ] シーン合成で背景に埋没しない（コントラスト）
