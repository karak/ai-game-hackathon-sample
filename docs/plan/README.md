# 計画ドキュメント（docs/plan/）

『マジカル☆リリカと血塗られたおとぎの国』を、現在の 3 ステージ POC から **8 ステージ構成のインディーズ完成版**へ育てるための計画一式。

| ファイル | 内容 | 更新頻度 |
|----------|------|----------|
| [00-vision.md](00-vision.md) | 製品ビジョン、対象、スコープ、設計の柱 | 変更時のみ |
| [01-status.md](01-status.md) | 現在地（実装済み・素材・テスト・予算の実測） | マイルストーンごと |
| [02-near-term.md](02-near-term.md) | 直近ゴール（次の 2 スプリント）と課題、受入基準 | 毎スプリント |
| [03-roadmap.md](03-roadmap.md) | M0〜M7 の長期ロードマップ、成果物、工数と生成予算 | マイルストーンごと |
| [04-stages.md](04-stages.md) | 8 ステージ構成案（テーマ・ギミック・敵・ボス・尺） | 設計変更時 |
| [05-systems.md](05-systems.md) | システム／ギミック／演出／音／デモ・エンディングの仕様バックログ | 随時 |
| [06-asset-pipeline.md](06-asset-pipeline.md) | 素材制作計画（生成手順・命名・予算配分・QA） | 随時 |
| [07-risks.md](07-risks.md) | リスクと対策 | マイルストーンごと |
| [08-backlog.md](08-backlog.md) | 不具合・技術的負債・改善の一覧（ID 付き） | 随時 |

## 運用ルール

- 進捗は **証跡付き**で更新する（テスト結果、スクリーンショット、生成台帳の番号）。主観語だけの「完了」は書かない（`docs/art-standard.md` §3）。
- 受入基準は各項目に「何を見れば OK か」を必ず書く。
- 生成リクエストは `tools/gen_ledger.json` の番号で参照する。
- 用語: **世界単位** = 論理座標 1px（画面 3px）、**セル** = 生成ドット絵の 1 画素（画面 1px）、**tick** = 1/60 秒。
