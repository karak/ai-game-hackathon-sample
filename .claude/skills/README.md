# プロジェクトスキル

| スキル | いつ使う | 検証 |
|--------|----------|------|
| retro-game-art-direction | 絵の品質判断・寸法/解像度の決定・進捗報告・カタログ作成の前 | 下位モデル（haiku）で基準なし報告→基準要求へ改善を確認（2026-09-08） |
| generating-pixel-art-with-gemini | 生成モデルでドット絵素材を作るとき | 下位モデルの「1024 を 64 で割る」「8 コマ 1 枚」「衣装 3 回生成」が、2 コマ構図・セル抽出・後処理派生へ改善を確認 |
| verifying-browser-games-with-bots | 画面に出る変更の動作確認・完了報告の前 | 下位モデルの「canvas 幅とタイトルのスクショだけ」が、通しプレイボット＋場面別証跡へ改善を確認 |

スキルは TDD（スキルなしで下位モデルを走らせ失敗を記録 → 作成 → 再実行）で作った。編集時も同じ手順を踏む。
